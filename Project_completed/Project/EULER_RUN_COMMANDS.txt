Euler run commands for the Heisenberg + DMI project
====================================================

Copy these files into your project root, preserving the scripts/ folder:

    scripts/make_euler_parameter_table.py
    scripts/submit_euler_array.sh
    scripts/build_on_euler.sh

On Euler, from the project root:

1. Build the C++ executable

    bash scripts/build_on_euler.sh

2. Generate the Euler parameter table

    python3 scripts/make_euler_parameter_table.py --mode full

This creates:

    parameters/euler_scan_D1.csv

Default production parameters:
    J = 1
    D = 1
    B = 0
    L = 16, 24, 32
    T = 0.8 ... 2.0, with refined points near 1.1 ... 1.6
    seeds = 1,2,3,4,5
    therm = 2000
    samples = 3000
    skip = 5
    proposal = 0.7

3. Submit the Slurm job array

The previous command prints the correct sbatch command, e.g.

    mkdir -p logs/euler results/raw results/processed
    sbatch --array=0-<LAST_RUN_ID>%64 scripts/submit_euler_array.sh

The %64 means at most 64 array tasks run at the same time.
Use %32 if you want to be more conservative.

4. Monitor jobs

    squeue -u $USER

or, if available on your Euler setup:

    myjobs

5. After all jobs finish

    python3 scripts/collect_results.py

6. Open analysis notebook

    jupyter lab notebooks/analysis.ipynb

or copy results/processed/summary.csv back to your laptop and run the notebook there.

Important:
- Do not run heavy simulations on the Euler login node.
- The login node is only for building, preparing parameter tables, and submitting jobs.
- The computation is done by Slurm compute nodes.
